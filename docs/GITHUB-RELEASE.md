This release contains the Firefox extension ZIP and its SHA-256 checksum.

Features include the responsive album List/Grid selector, playable video-cover artwork, and the smaller bottom-right now-playing indicator.

The ZIP is an **unsigned Mozilla Add-ons submission package**. For temporary testing, select the ZIP directly through Firefox's Load Temporary Add-on control on about:debugging. Standard Firefox requires Mozilla signing for permanent installation.

This GitHub release does not submit to or publish on Mozilla Add-ons. Source archives are available through GitHub's automatic source-code downloads.
Version 1.1.0 adds an Options page with opt-in playlist support, video-preview control and a compact native indicator toggle. Playlist support defaults to off.
