This release contains the Firefox extension ZIP and its SHA-256 checksum.

Features include the responsive album List/Grid selector, playable video-cover artwork, and the smaller bottom-right now-playing indicator.

The ZIP is an **unsigned Mozilla Add-ons submission package**. For temporary testing, extract it and load manifest.json through Firefox's about:debugging page. Standard Firefox requires Mozilla signing for permanent installation.

This GitHub release does not submit to or publish on Mozilla Add-ons. Source archives are available through GitHub's automatic source-code downloads.
